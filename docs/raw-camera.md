# RAWカメラ

mainのナビゲーションフォルダー内、6番のRAWアイコンから開きます。

背面の各物理レンズで利用できるBayer RAW / Apple ProRAWを実行時に判定します。RAW非対応の機種・レンズではシャッターを無効化します。JPEGをRAWと表示する代替動作はありません。ライブビューには現像後のルックを適用せず、撮影後のギャラリーで仕上がりを確認します。縦向き静止画専用です。

画面をタップするとピントと測光位置を指定できます。露出補正、レンズ切り替え、RAW / ProRAW切り替え、グリッドを備えています。ProRAWのみ対応するレンズではProRAWを使います。

DNG原本はDocuments/RawCameraへ保存し、独立したJSONに編集内容を記録します。Cinema / Neutral / Mono、露出、色温度、彩度、コントラスト、粒子を調整できます。編集画面を離れると調整を保存します。原本は上書きしません。現像に失敗した場合も原本をギャラリーからDNGとして共有できます。

書き出しはJPEG / HEIC / DNGです。JPEGとHEICは元の解像度で再現像し、DNGは無加工の原本を共有します。JPEG / DNGは写真ライブラリへの保存にも対応します。「撮影後にJPEGを写真へ保存」を有効にすると現像後に自動保存します。写真の追加権限だけを要求します。アプリ削除で内部原本も削除されるため、必要な原本はDNGで書き出してください。

Chromagraphの公開説明にある「RAWから現像し、原本を残す」撮影フローを参考にした独自実装です。Chromagraph固有の色変換やSteve Yedlinの処理を再現するものではありません。

GitHub ActionsのmacOS 26 / Xcodeで既存mainと全拡張をビルドし、main-ipa Artifactに未署名IPAを出力します。[raw]コミットはRAW画面のシミュレーターUIチェックを実行します。シミュレーターのチェック対象はカメラ非対応の表示、シャッター無効化、設定、空のギャラリー、ホーム復帰です。カメラセンサー、DNG生成、実RAW現像、写真保存、撮影画質は実機確認が必要です。

RAW自動チェックはRawDBのCC0 iPhone 6s Plus実写Bayer DNGを使用し、RAW現像、編集反映、粒子の再現性、プレビュー縮小、原本保持、編集の再読み込み、JPEG/DNG書き出し、無効RAWのエラーと原本保持を検証します。実センサーのDNGとの互換性・画質を代替する検証ではありません。
