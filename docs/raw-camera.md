# RAWカメラ

mainのナビゲーションフォルダー内、6番のRAWアイコンから開きます。以前のmainの機能・ホーム配置・写真データを引き継ぎます。

## 撮影

画面上部で12MP/最大48MPとRAW/ProRAW/HEICを選びます。センサーの対応する写真サイズを取得し、出力と撮影要求の両方へ設定します。48MPを要求してもOSが小さい画像を返す場合があるため、保存ファイルから画素数を読み直して記録します。要求サイズを保存サイズとして流用しません。48MP未満で撮影された場合は実寸を通知します。補間で48MPへ拡大する機能はありません。

RAW・ProRAWの対応は機種とレンズに依存します。ProRAW非対応機でもセンサーとAPIが対応していればHEICの48MP撮影を選べます。HEICをRAWとして表示・保存しません。RAWはDNG、HEICはHEICの原本を保持します。2倍ズームでは12MPを選択し、48MPの選択時には1倍へ戻します。48MPの実機撮影可否・画質は撮影結果で確認が必要です。

背面/前面切替、物理レンズ切替、2倍ズーム、露出補正、タップ測光・AF、長押しAE/AF固定、グリッド、3秒/10秒タイマー、対応時のフラッシュ、初期レンズ、前面ミラー表示、撮影比率に対応します。比率は非破壊のクロップとして保存し、原本の画素は捨てません。縦向きの静止画アプリです。ライブビューには現像ルックを適用せず、撮影後に仕上がりを確認します。

## 閲覧と編集

月別グリッド、複数選択、削除確認、ビューアーとフィルムストリップ、撮影日時・原本解像度・ISO・シャッター・絞り・色温度・ファイルサイズを備えます。画像の長押しで未調整との比較ができます。

- Tone: 露出、コントラスト、ハイライト、シャドウ、黒レベル。
- Color: 色温度、ティント、彩度、Cinema/Neutral/Mono。
- Texture: GrainのAmplitude・Size・Force Pixel Size、HalationのAmplitude・Size。
- Crop: 比率、拡大・位置、90度回転、左右・上下反転。ピンチとドラッグも使用できます。

調整の取り消し・やり直し、リセット、標準現像設定の保存に対応します。粒子は固定シードの画素位置から生成し、繰り返す小さなテクスチャを使いません。現像はCore Imageで行う独自処理です。編集画面を離れると調整を保存し、原本は上書きしません。古い編集JSONも読み込めます。

## 読み込み・保存

写真ピッカーまたはFilesからDNG/HEIC/JPEG/PNG/TIFFを読み込めます。原本と編集はDocuments/RawCameraに保存します。現像エラー時も原本を残します。アプリの削除で内部の原本も消えるため、必要な写真は書き出してください。

JPEG/HEICの書き出しは元のサイズ、長辺4096/2048/1280/1080pxを選択できます。原本以上には拡大しません。原本は未加工で共有でき、DNG原本を写真に保存することもできます。JPEG/HEICは撮影EXIFと実際の出力画素数を記録し、位置情報は設定で含める場合だけ引き継ぎます。撮影後の写真への自動保存はJPEG/HEICとサイズ設定を使います。

複数の原本と編集・撮影情報は.rawcameraパッケージとしてアーカイブ出力・読み込みできます。復元時は新しいIDを割り当てて既存写真を上書きせず、途中で失敗した場合は作成したファイルを戻します。これはこの実装の形式であり、Chromagraph固有のアーカイブとの互換を意味しません。

公式App Storeの説明・リリースノート・4枚のスクリーンショット、開発元サイトを参照しています。RAWからの現像、原本保持、Tone/Color/Texture/Crop、粒子の3項目、Halation、Undo/Redo、EXIF表示、月別一覧・フィルムストリップ、読み込み、自動書き出し、サイズ・初期レンズ・ミラー・反転・アーカイブという公開機能を対象にしています。公開されていないYedlin固有の色変換・係数、独自ファイル形式の完全互換、機種別の画質一致は保証できません。Chromagraphのコード・画像・ブランド素材は組み込んでいません。

GitHub ActionsのmacOS runnerとXcodeでmainと既存拡張をビルドし、main-ipa Artifactを出力します。RAWチェックはRawDBのCC0 iPhone 6s Plus DNGを使用し、現像・編集・固定粒子・クロップ・出力寸法・EXIF・原本保持・旧編集の読み込み・JPEG/DNG読み込み・混在アーカイブの復元と失敗時の巻き戻しを確認します。テスト画像は製品アプリに含めません。

[raw]のUIチェックはカメラ非対応表示、シャッター無効化、設定、空ギャラリーに加え、Debug限定の独立したテスト保存先へDNGを読み込んでビューアー・編集・Undo/Redo・クロップ・書き出し画面を操作します。実機での48MP撮影、RAW生成、写真保存・画質の確認はCIとは別の検証です。
