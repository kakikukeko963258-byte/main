# 写真リスニング（アプリ2）

最新版mainのアプリ1（PC File Bridge）と既存のホーム・フォルダ・Switcher・Files拡張・同梱WDAを維持し、空いていたアプリ2に写真リスニングを追加。

- 写真1〜3、各1〜4章を収録。数研出版「Revised BLUE MARBLE English Communication I」の教材音声MP3（章12本＋写真全体3本）をオフライン再生。写真1はLesson 6、写真2はLesson 7、写真3はLesson 8。
- 選択範囲のループ・全体の順番再生ループ・速度変更・15秒移動・スリープタイマー。
- 再生時刻を使って単語を黄色く表示。速度変更、一時停止、シーク、ループ時にも音声の時刻を使う。単語時刻はWav2Vec2の音響確率を使ったCTCアラインメントで作成し、教材の段落開始時刻ごとに位置を合わせる。数値・略語の読みを正規化し、原文のUTF-16範囲に対応させる。
- ハイライトが表示欄の上半分にある間は動かさず、下半分に入り、かつ表示欄内にある間だけ行を追従。手動で欄の外へスクロールしても引き戻さない。末尾は下端までスクロールできる。単語のタップでその音声時刻へ移動。
- ホームへ戻ってもモデルを維持し、画面ロック中の音声再生に対応。

`Main/Listening/Resources/word-timings.json` は各MP3の音声秒と原文のUTF-16範囲。`photo-N-full` の原文は各章を改行2つで連結したもの。

単語タイミングは端末の音声認識やマイクを使わず、ビルド前に作成したデータのみで動作する。

## 音声の更新手順

`scripts/prepare-listening-audio.py` が、公開書籍目録のLesson 6〜8のOVERVIEWから3本の全文音声と段落情報を取得し、段落開始時刻で各章へ切り出す。単語時刻は続けて `scripts/refine-listening-word-timings.py` で更新する。Wav2Vec2 ONNXモデルと語彙ファイルを `--model` と `--vocab` で指定する。モデルは作成時だけ使い、アプリには含めない。

`Main/Listening/Resources/audio-sources.json` に教材ページ・音声・段落情報のURL、全文MP3のSHA256、章開始時刻を記録。全文MP3は取得した原本をそのまま保存し、章のMP3のみ再エンコードする。音声はアプリに同梱するため、利用時に教材サイトへの接続は不要。
