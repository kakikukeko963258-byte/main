# 関東 乗車ナビ（ホームの5）

最新保存コミット e44d867 を土台に、既存機能を残して追加。

- 「自動検知を開始」で使用中のみ位置情報を要求。GPSの経路・移動履歴で路線候補を絞り、駅付近で15秒以上の低速を停車、連続測位中の高速通過を通過の観測として記録する。
- 位置が100mより不正確、古い、時系列が逆、異常な飛びの場合は採用しない。45秒以上の欠測で観測をリセット。100m以下でも50mより不正確な測位は停車・通過に使わない。
- 実線形と照合。移動300m以上かつ複数回の速度観測が揃うまでは乗車と扱わない。並走路線の差が40m以下なら自動選択しない。
- 種別ごとの停車パターンと照合し、同一路線で2駅以上の停車・通過を観測、方向既知、種別候補が1つのときに「○○の可能性」と表示する。速度だけから急行とは判断しない。
- 同じ停車駅で種別が違う場合、GPSが取れない地下、バスや車が線路沿いを走る場合などは識別を保証できない。路線・種別・方向・行き先を手動補正可能。
- 自動時は停車／通過の候補と全線の駅を表示。手動で停車パターンを選択すると、その方向と行き先の停車駅を表示する。乗換駅は駅グループの明示的な対応から取得する。
- 履歴はメモリ内だけで使用。バックグラウンドや画面を閉じると測位停止。30秒未更新で前回候補と明示。通常の使用では通信・APIキー不要。

## データ

[Mini Tokyo 3D](https://github.com/nagix/mini-tokyo-3d) のリビジョン `68314fe92773aa4691075b79243f2010fc8e2836` から、179路線、2583駅レコード、2624停車パターンを取得。取得日2026-10-21。関東1都6県と周辺県に延びる区間を含む。関東の全路線・臨時列車を保証するものではない。実際の収録路線・種別・駅数はアプリ内の「収録路線・データの出典」で確認できる。

元データ：公共交通オープンデータセンターおよび参加交通事業者。Mini Tokyo 3DのMITライセンスを同梱し、アプリ内からも表示。原データの利用条件： https://developer.odpt.org/terms 。アプリは時刻表の時刻を使わず種別と停車パターンのみを抽出し、営業日の推定、遅延・運休の反映は行わない。収録日とダイヤの改正日は異なる。

`python scripts/import-rail-data.py` で同一リビジョンから再生成できる。データ更新時はリビジョン・取得日・出典を更新し、検証を再実行する。

## 検証

GitHub ActionsのmacOS/XcodeでアプリとIPAをビルド。`RailChecks.swift` は実収録データの整合性・主要事業者・急行/快速/特急の存在、停車と通過による候補の除外、GPS欠測、位置の鮮度、静止時、環状線、乗り換えを検証する。UIテストは路線と種別の選択・停車駅・乗換詳細を確認する。実際の電車での検知精度は実乗車で別途検証が必要。
