# main

iPhone用のSwiftUIアプリ。写真を参考にした4列×6行のホーム画面に、合計32個の番号付きアイコンをフォルダとともに配置し、各番号のページへ移動します。左上の戻るボタン、または画面左端からのスワイプで戻れます。

アプリ名・プロジェクトIDは `main`。iOSのBundle IDは `com.kakikukeko.main`、iOS 16以降に対応します。iPhoneホーム画面風の壁紙・角丸アイコン・番号ラベルを使用し、写真の6行配置に合わせ、画面高に応じて行間を調整します。ステータスバーは実際のiOSの表示です。OSのホーム画面を置き換える機能や、他のIPAをこのアプリ内にインストールする機能はありません。

## 公開ビルド

mainへのpushまたはActionsの手動実行でmacOS runner + XcodeがReleaseビルドします。Actions Artifact `main-ipa` とGitHub Releasesから `main.ipa` を取得できます。

普段のインストールは設定済みの改造版AltForge Remoteを使用します。公開IPAのハッシュを確認し、許可済みIPAフォルダーへ追加して登録済み端末へ署名・転送します。接続情報は公開しません。

WindowsではXcode不要です。AltStore Classicを手動で使う場合は、ダウンロードしたIPAをiPhoneのAltStore Classicの「My Apps」→「+」から選んでインストールしてください。IPAは未署名で、AltStore側でApple IDを使って再署名します。AltStore PAL向け配布ではありません。

## 拡張

`Main/MainApp.swift` の `HomeItem` と `SlotPage` を拡張すると、番号ごとの機能を追加できます。外部のiOSアプリを埋め込むのではなく、このプロジェクト内に機能を実装する構成です。

## 写真のレイアウトを反映した版

4列×6行のホーム画面を基準に、上段右側へ「ナビゲーション」（3〜7）と「ユーティリティ」（8〜12）を配置。番号1〜32をすべて残しています。写真のアイコン幅・左右の余白・行間・ラベル位置を画面サイズに比例させ、実際のiOSステータスバーを表示します。時刻・電波・バッテリーはOSが管理する実際の値です。Dockはありません。

アイコンを長押しして別のアイコンへドラッグするとフォルダを作成・統合できます。フォルダ上部の名前をタップして変更、フォルダ内の番号を長押しするとホームへ取り出せます。配置は端末内に保存します。24項目を超えると次のページが増えます。

iOS 26以降は標準のLiquid Glassをフォルダと操作ボタンに使用し、それ以前はマテリアルへ切り替えます。アイコンはガラス調の描画をキャッシュして表示します。フォルダ展開の位置補間、背景ぼかし、押し込み、ページ開閉にスプリングアニメーションを使用し、「視差効果を減らす」設定に対応します。

元の壁紙ファイルは取得できていません。画像から色・ぼけを参考に再現した背景です。「検索」画面左上の写真ボタンから任意の背景を選択できます。選んだ写真は端末内だけに保存されます。参考スクリーンショット自体は公開リポジトリに含めません。


## 名前・描画・移動の修正

単独になったアイコンには番号名だけを表示し、古いフォルダ名を閉じる処理で書き戻しません。保存済みの単独アイコン名も読み込み時に修復します。

アイコンと標準背景は画像としてキャッシュし、アニメーション中に何十個ものガラス効果と背景ぼかしを再描画する負荷を削減しました。実際のLiquid Glassはフォルダと操作部に使用します。インタラクティブガラスの丸いハイライトを除去しています。

長押しするとアイコンのメニューが開きます。そのまま指を動かすとメニューが閉じ、編集状態でアイコンを移動できます。「ホーム画面を編集」からも編集できます。アイコンのみが指に追従し、離すと並べ替えます。別のアイコンの中央へ0.65秒以上重ねてから離すとフォルダへまとめます。フォルダ内の長押しで表示される「−」、またはフォルダの外へのドラッグで取り出せます。「完了」またはアイコンのない場所のタップで編集を終え、揺れも確実に停止します。標準のコピー用「＋」バッジや大きな円形ドラッグプレビューは使用しません。

番号ページの開閉は、固定サイズのページを一度キャプチャし、UIKit/Core Animationでその表示面を拡大・縮小します。アニメーション完了後は操作可能なSwiftUIページに戻します。開閉中の毎フレームのページ再配置・輪郭パス生成と、ホーム全体への追加ぼかしを除去しました。フォルダの開閉は既存の方式を維持しています。実機でも番号ページを開く動きが滑らかになったことを確認済みです。


## 1番: PC File Bridge

ホーム画面の「1」を開くとWindows PCとのペアリング画面を表示します。Windows側のPC File Bridgeを起動し、PCのアドレスと6桁コードを入力すると、共有フォルダーをアプリ内から閲覧でき、File Provider拡張をiPhoneの「ファイル」に登録します。左上の戻るボタンでmainのホームへ戻れます。

本体のBundle IDは`com.kakikukeko.main`、拡張は`com.kakikukeko.main.FileProvider`です。拡張分のApp IDも署名時に必要です。共有領域は`group.com.kakikukeko.main.pcfilebridge`を使い、AltStoreによる末尾の名前変更は署名済みプロファイルから解決します。以前の単独PC File Bridgeアプリの登録情報は引き継がず、mainで再ペアリングします。

IPAには本体と拡張のApp Group宣言を仮署名で保持し、インストール時にAltForge/AltStoreがApple IDで再署名します。インストール時にはFile Provider拡張を保持してください。実機でのPCとの接続と「ファイル」からの読み書きは、再署名してインストールした端末での確認が必要です。


## 外出先からの自動再接続

PCとiPhoneで同じTailscaleをオンにすると、保存したVPNアドレスへ接続します。mainの「1」を開くと保存済みの接続情報で認証を確認し、切断中も情報を消さずに再試行します。初回登録後はアドレスとコードの入力欄を隠し、別のPCを追加するときだけ表示します。

`PCFileBridgeSetup.json`を「初回設定を読み込む」から取り込めます。設定は期限付きの初回コードとPCのプライベートアドレスだけを含み、長期トークンはペアリング後に保護された共有領域へ保存します。`scripts/prepare-private-connection.ps1`で、改造版AltForgeへの配布直前に初回設定をIPAへ加えることもできます。この個別設定済みIPAは許可済みのローカルフォルダーだけに保存し、公開ArtifactやGitHub Releasesには送信しません。期限切れの場合はPCで設定を更新してください。
